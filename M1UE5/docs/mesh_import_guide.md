# ⛔ SUPERSEDED — Mesh Import Guide

This document described importing the hand-modeled OBJ kit pieces into UE5.
**It has been superseded** by the procedural-sector approach: level geometry
is generated automatically from `Reference/Maps/*.json` rather than placed
piece by piece.

See instead:

- `M1UE5/CLAUDE.md` (Level design conventions section)
- `M1UE5/docs/pipeline_roadmap.md` — the `.scen` → UE5 converter milestone

The OBJ files in `Content/Meshes/Modular/` remain in the project as fallback
art and historical reference, but no new content should rely on them.
